# SDMs
Multispecies Modelling

All data and results are stored on the Lowestoft CDP under XXX

NS-IBTS data processing.R   script to clean datras data for selected species and extract covariates for each haul location
cod_models.R                initial models were fit and tested for the NS-IBTS cod data, this code is useful to refer back to for understanding the model fitting process for all species
spatiotemporal_models2.R    model fitting for all species, using a custom function and backwards elimination for model selection. Function saves a list of all models to 'res' folder and a results table comparing the models using cAIC, sanity checks [refer to sdmTMB documentation] and the formula for the model. Model names as follows 'dln' delta-lognormal 'dg' delta-gamma 'tw' tweedie; 'full' the full model with all covariates included 'redX' how many times the model has been reduced; 'svQ' including Quarter as spatially-varying; 'Sri' includes Ship as a random intercept. This is the main script to run all the models.

future_predictions_grid.R   creates a grid of points in the north sea for each of the years to predict for and saves as an Rds under 'predictions' folder. This needs to be run before the species predictions scripts.
cod_predictions.R           future predictions for cod. Best model is selected manually based on the results table generated by spatiotemporal_models2.R script (and some tweaking to see if anything improves this a little!)
haddock_predictions.R       same as above but for haddock
whiting_predictions.R       same as above but for whiting. 


Predictions were only made for cod, haddock and whiting due to time constraints but were aimed to be completed for all species.
Norway pout data looked very sparse so there is less confidence in the results of this model - unsure why since N. Pout are often caught in the NS-IBTS survey so worth re-downloading from DATRAS

Covariate data is extracted from 'new_gridded_env_data_10km_1980to2099_CERES_Copernicus_and_other_sources' which Elena Couce pre-processed. This data is stored on the CDP.
